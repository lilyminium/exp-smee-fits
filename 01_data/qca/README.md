# Download and postprocess QCA data

The scripts here download and re-format QCArchive data.
It takes advantage of data downloaded and processed for
the Sage 2.3.0 fit.

This data has been copied over into `sage-data-pool` for
convenience. Please see the Sage 2.3.0 01_download-data/
directory for more; a representative script for
re-downloading can be found in `download_sage_pool.py`.
